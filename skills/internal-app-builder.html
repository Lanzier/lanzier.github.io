internal-app-builder — 为团队快速搭建可上线的多人网页工具，一条龙交付
SKU索引GitHub Pages定时自动化液态玻璃UI本地文件打开

🧠 它能做什么

把「共享盘/内网系统数据 → 网页工具 → 团队使用」全流程自动化。不用写服务器、不用买域名，从数据到上线一站式解决。

✅ 核心能力

  • ① 全量索引构建 — 扫描共享盘/内网数据，识别 SKU/编号/关键词，自动建索引（带断点续扫，上万文件不丢进度）
  • ② GitHub Pages 部署 — 一键推到 GitHub，免费公网固定域名，同事随时访问，无需自己跑服务器
  • ③ 定时自动更新 — Windows 定时任务每天自动重建索引并推送，数据永远最新，无需手动干预
  • ④ 精美 UI — iOS 液态玻璃质感、中英切换、日夜模式、动态光斑，专业又好看
  • ⑤ 打开本地文件 — 自定义协议（sku-open://）+ 本地脚本，网页点按钮直接打开共享盘文件夹
  • ⑥ 一键分发 — 打包安装包，同事双击一次即装，无需配置

🎯 适用场景

  • 🔍 按 SKU / 编号 / 别名 查共享盘文件路径
  • 📊 内网报表、产品资料检索
  • 🛠️ 团队多人访问的内部网页工具
  • 📦 需要打包分发给同事的工具

🛡️ 免费 · 开源

完全免费开源，零服务费。数据保存在自己的共享盘和本地，不上传任何第三方。
