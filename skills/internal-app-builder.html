🧠 能力概览Overview

为团队快速搭建可上线的多人网页工具。核心链路：数据从共享盘/内网系统取出 → 建索引 → 部署到 GitHub Pages（公网固定域名） → Windows 定时自动更新 → 液态玻璃 UI → 必要时用自定义协议打通本地文件打开。一条龙交付。Quickly ship multi-user web tools for your team. Index data → GitHub Pages → auto daily update → liquid-glass UI → custom protocol to open local files. End-to-end delivery.
