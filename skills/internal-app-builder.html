🧠 它能做什么What It Does

把「共享盘/内网系统数据 → 网页工具 → 团队使用」全流程自动化。不用写服务器、不用买域名，从数据到上线一站式解决。Automates the whole "shared-drive data to team web tool" pipeline. No server, no domain — from data to launch in one flow.

✅ 核心能力Core Abilities

  • ① 全量索引构建Index Building — 扫描共享盘/内网数据，识别 SKU/编号/关键词自动建索引（断点续扫，上万文件不丢进度）Scan shared drive & build index, auto-detect SKU/codes (checkpoint resume, no progress loss).
  • ② GitHub Pages 部署GitHub Pages Deploy — 一键推 GitHub，免费公网固定域名，同事随时访问，无需自建服务器Push to GitHub, free public fixed domain, no server needed.
  • ③ 定时自动更新Auto Update — Windows 定时任务每天自动重建索引并推送，数据永远最新Scheduled daily re-index & push, always up to date.
  • ④ 精美 UIPolished UI — iOS 液态玻璃质感、中英切换、日夜模式、动态光斑Liquid-glass UI, bilingual, day/night, animated glows.
  • ⑤ 打开本地文件Open Local Files — 自定义协议 + 本地脚本，网页点按钮直接打开共享盘文件夹Custom protocol + local script, open shared-drive folder from web button.
  • ⑥ 一键分发Distribution — 打包安装包，同事双击一次即装Pack & one-click install for teammates.
