🔮 补货预测引擎Restock Forecast Engine

基于去年同期月销量 + 近 30 日均值，三种运输方式独立计算（空运 14 天 / 限时达 30 天 / 快船 40 天），按月四周输出补货建议表格，一键导出 CSV。Based on same-month sales last year + 30-day average. Three shipping methods calculated independently (Air 14d / Express 30d / Sea 40d). Weekly restock table with CSV export.

📋 安装方式Installation

配置领星 MCP 连接后即可使用：One MCP config command to connect:

openclaw mcp add LingXing-MCP --transport streamable-http --url http://openmcp.lingxing.com/mcp-servers/lingxing-mcp --header X-Mcp-Key=<你的领星API密钥>

需要领星 ERP 账号和 MCP API Key（联系领星获取）Requires LingXing ERP account and MCP API Key (contact LingXing for access)
